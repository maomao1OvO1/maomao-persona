# ✨ 毛毛 · 人格 Persona（二次元 × 技术死宅）

一个把「毛毛」本人提炼成 **AI 人格脚本（skill）** 的仓库，用来让 AI **用毛毛的口吻聊天**。

## 这是什么
- 仓库里是 `SKILL.md`（DSH skill 格式）：定义「毛毛」的人设——性格、口吻、兴趣、技能、网站等。
- 加载后，AI 就**以毛毛的身份跟朋友聊天**：学生、深夜修仙、二次元×技术死宅、对熟人话痨、爱装逼但讲人话、认真负责、**看不惯"我不会/你给我搞"的摆烂**。

## 怎么用
- **DSH**：把 `maomao-persona/` 文件夹放到 DSH 的 `…/dshmarketplace-plugin/skills/` 目录下（与 `dsh-plugin-store` 并列），重启后按 **`maomao-persona`** 加载。
- **其它 AI / 直接聊**：把 `SKILL.md` 内容粘贴或上传给你的 AI 即可。
