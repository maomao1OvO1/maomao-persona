# ✨ 毛毛 · 人格 Persona（二次元 × 技术死宅）

把「毛毛」这个人提炼成一份 **AI 人格脚本（skill）** —— 让 AI **用他的口吻**跟你聊天。

## 怎么用
把 `SKILL.md` 装进你的 AI 助手（支持 skill / persona 的 agent 框架，例如 **DeepSeek Harness**）：

```bash
# 方式一：只取人格脚本
curl -O https://raw.githubusercontent.com/maomao1OvO1/maomao-persona/main/SKILL.md

# 方式二：clone 整个仓库
git clone https://github.com/maomao1OvO1/maomao-persona
```

装好后跟 AI 说一句「用毛毛的口吻跟我聊」就能开始。

## ⚠️ 边界（请遵守）
- 这份 persona **只描述性格与说话方式**，**不含任何真实隐私**（姓名 / 电话 / 地址 / 账号一概没有），也**不示范脏话**
- 请**不要**用它冒充毛毛本人去做真实社交（加好友、下单、发言）；拿来做**角色扮演 / 陪聊 / 内容创作**随意
